Type Mermaid on the left; the diagram redraws as you type. Pick a sample from Example, a palette from Theme, and save the result with Download SVG. If the source does not parse, the error names its line and column.

Run it yourself

Render diagrams from Go, with no browser or Node:

go get github.com/zkrebbekx/go-mermaid

svg, err := mermaid.Render("flowchart LR\n  A --> B", mermaid.WithTheme(mermaid.Dark))

Or from the command line, as SVG or PNG:

go install github.com/zkrebbekx/go-mermaid/cmd/mermaid@latest
mermaid -o diagram.svg diagram.mmd
mermaid -png -scale 2 -theme dark -o diagram.png diagram.mmd

To run this site locally (needs Go 1.26.8 or newer and Python 3):

git clone https://github.com/neomantra/go-mermaid
cd go-mermaid
make serve-site   # http://localhost:8000/
